# Card Predict Students' Dropout and Academic Success

* **Penerbit:** UCI Machine Learning Repository (Disumbangkan oleh Valentim Realinho, dkk., 2021)
* **DOI:** 10.24432/C5MC89
* **Lisensi:** CC BY 4.0
* **Deskripsi:** Dataset ini berisi 4.424 data anonim mahasiswa di Portugal, mencakup 36 atribut demografis, makroekonomi, dan kinerja akademik pada semester 1 dan 2.
* **Target Variabel:** `Dropout`, `Enrolled`, `Graduate`
